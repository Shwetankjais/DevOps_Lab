# Lab 3: Git Branching, Merging, Conflict Resolution and Rebasing

## Objective
To practise creating and switching branches, merging feature branches,
resolving merge conflicts, and rebasing branches using Git.

## Part A: Creating and Switching Branches
Commands practised:
- git branch
- git branch feature-login
- git checkout feature-login
- git checkout -b feature-signup

## Part B: Merging Branches
Create login.txt on feature-login, commit the change, and merge it into main.

## Part C: Merge Conflict Resolution
Modify notes.txt differently on main and feature-version, attempt the merge,
inspect the conflict markers, resolve the conflict, and commit the result.

## Part D: Rebasing
Create divergent commits on feature-rebase-demo and main, then rebase the
feature branch onto main and inspect the resulting history.
